Privacy

Northcomm Spec Lookup · last updated 14 September 2026

Northcomm Spec Lookup is a public page for reading the factory test report on file for a Northcomm cable assembly. There is no sign-in and no account.

What we collect

Nothing. The page does not ask you to sign in, does not set tracking cookies, and runs no analytics, advertising, or third-party trackers. The serial you type stays in your browser and is used only to look up its report.

How the lookup works

When you enter a serial, the page reads a public, read-only catalogue of published test reports from Northcomm's database, hosted by Supabase. It sends the serial you typed so the matching report can be returned. The catalogue and the report documents describe hardware, not people, and contain no personal information.

Requesting a missing report

If you use a request link and no report is on file, your own email app opens with a blank message. You decide what to write and whether to send it. We receive only the email you choose to send.

Children

This is a workplace reference tool and is not directed at children under 13.

Changes

If this policy changes, the date at the top of this page will be updated.
