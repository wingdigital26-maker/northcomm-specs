Northcomm Spec Lookup

Northcomm Spec Lookup pulls up the factory test report on file for a Northcomm cable assembly. Type the serial printed on the label and its report opens. No sign-in, no account.

Need help?
Email support@northcomm.app

Looking up a serial

  1. Find the serial on the label attached to the cable assembly. It starts with "NC" and a number, for example NC-121483.
  2. Type it into the search box on the home page. Dashes, spaces and case are ignored, so 121483 and NC-121483 both work.
  3. Choose Retrieve. The matching report and its specs appear below.

Browsing every report

The home page lists every report on file under "Published reports." Choose any row to open its specs and full report.

Nothing comes up for a serial

If the page says no report is on file, check the digits against the label. If it still is not here, the report may not be published yet. Use the request link on the page and Northcomm will locate the assembly and upload it.

The report will not open

Choose Open full report to open the PDF in a new tab. Reports are large documents, so on a slow connection one can take a few seconds to arrive. If your browser blocks the new tab, allow pop-ups for this page and try again.

What is in a report

The factory sweep test for that exact assembly: VSWR and insertion loss across the swept range, the pass or fail result, and the test date. The PDF is the same document that shipped with the cable.
