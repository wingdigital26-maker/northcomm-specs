On the page

What's in a report.

The factory sweep test for that exact assembly. Nothing generic, this is the actual bench data for the serial you typed.

VSWR

Voltage standing wave ratio across the swept frequency range.

Insertion loss

How much signal the assembly loses end to end.

Time-domain trace

Where along the cable a reflection occurs, if any.

Pass or fail

The bench result recorded on the day it was tested.

Questions

A few things people ask.

Where is the serial number?+
Printed on the label attached to the cable assembly, starting with "NC" and a number. Some labels also carry a QR code that opens the report directly.
The serial isn't found.+
Check the digits against the label. If it still isn't here, there may be no report on file for it. Older assemblies and cables without a serial label were not part of this program. The Support page has the contact details if you need help.
What's in a report?+
The factory sweep test for that exact assembly: VSWR and insertion loss across the swept range, the pass or fail result, and the test date. The PDF is the document that shipped with the cable.
Do I need an account?+
No. Anyone with a serial can pull its published report here. No sign-in.
